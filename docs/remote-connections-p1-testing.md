## 2. 手动验收

准备：
- 一份**升级前**的 userData，里面有 2 个以上远程 agent，最好有两个在同一台服务器上，并且至少一个开了「允许好友调用」。
- 一台能免密 SSH 登录的服务器，装有 `codex` 或 `claude`。
- 运行 `npm run dev`。

### 2.1 迁移

1. 升级前先记下：每个远程 agent 的 host、参数、是否共享；给一个远程 agent 在某会话里选好服务器目录（P0 的功能）；在会话里让它记住一个暗号。
2. 用新版本启动。检查 userData 目录：
   - `connections.json` 存在，权限为 `-rw-------`。
   - 同一台服务器只生成一个连接。
   - `local-agents.json` 里已没有 `remote` 字段，换成了 `remoteAgent.connectionId`。
   - `local-agents.json.bak-before-connections` 是升级前的原文件。
   - 有 `connections-migration.done`。
3. 设置 → 智能体：所有远程 agent 都在，参数没变，标记为远程。
4. 回到第 1 步选过目录的会话：目录仍然生效，并且能答出暗号（目录和会话续接都没有因迁移而失效）。
5. 共享权限：原本没开共享的 agent，迁移后仍不能被好友调用；原本开了的仍可以。再到连接页给一个原本不共享的连接打开共享：它上面原本不共享的 agent 依然不能被好友调用，必须在 agent 编辑器里单独勾选。
5a. 容错：在升级前的 `local-agents.json` 里手动把某个远程 agent 的 host 改成非法值（如 `a b`），再升级。预期：启动时弹出提示，列出这个 agent 的名字；它原样留在 `local-agents.json` 里；其他 agent 正常迁移；之后在设置里增删其他 agent，这条记录也不会消失。
6. 重启一次，确认什么都没变。

### 2.2 连接页

7. 设置 → 连接：每行有开关、名称、`user@host`、状态点。连接正常时显示「已连接 · xx ms」。
8. 点「添加」，从 `~/.ssh/config` 的 Host 中选一台，保存，状态变为已连接。用户、端口、密钥留空时使用 SSH 配置。
9. 「…」→「测试连接」：逐项显示 SSH 登录、Shell 与 base64、登录 PATH 与主目录、服务器上的私有目录、套接字转发。
   - 在服务器 sshd 里关闭 `AllowStreamLocalForwarding` 再测一次：前四项通过，套接字转发失败并给出原因，测试整体仍算通过。
10. 点扫描图标：列出服务器上找到的 CLI、路径和版本。勾选后添加，它们会出现在 设置 → 智能体 里，名称为「Codex · 连接名」。
11. 「…」→「在终端打开」：打开终端并 SSH 登录到该服务器。

### 2.3 停用、编辑、删除

11a. 好友正在调用你共享的服务器 agent 时，在连接页把共享关掉。预期：好友的这次任务被中止。

12. 有远程 agent 正在回复时，关掉它所在连接的开关。预期：当前回复立即停止；再发消息时报错「连接已停用」；**任何情况下都不会在本机运行**。打开开关后恢复正常。
    停用状态下打开含这个 agent 的会话详情：其他成员的工作区设置正常显示，这个 agent 那一行不显示。
13. 编辑一个已被 agent 使用的连接，把用户改成另一个账号。连接页的状态应很快变成新账号的检查结果，不会卡在「连接中」。预期：弹出确认（会中止进行中的任务、旧目录失效）；保存后，之前选的服务器目录显示「属于另一台电脑或服务器」，会话开新 thread。只改名称则不弹确认，也不影响任何东西。
14. 删除一个被 agent 使用的连接：
    - 选「保留」：agent 出现在「服务器不可用」分组里，打开编辑器会提示连接已删除，可以改选另一个连接。
    - 选「一并删除」：没有被联系人使用的 agent 被删除；仍被联系人使用的 agent 会保留下来，但不可用。
15. 断网或关掉服务器：状态变为错误并显示原因和重试时间。恢复后，切回 Douchat 窗口会立即重试，不用等退避时间。

### 2.4 Agent 编辑器

16. 添加 agent → 运行位置选「远程服务器」：只有「连接」下拉框，没有 host 输入框；已停用的连接是灰的；没有连接时提示先去连接页添加。
17. 连接未开共享时，编辑器里不显示「允许好友调用」；连接开了共享时，可以对单个 agent 取消勾选来收紧。

## 3. 本期不包含

以下属于 P2，本期不验收：
- 守护进程连接（`douchat-host`）和服务端的绑定、租约、签名、审批。
- 连接页的「守护进程」标签：目前只有 SSH，守护进程标签留到 P2。
- 跨连接或跨桌面的分布式目录锁。锁仍只在同一桌面进程、同一连接内生效。
