# 对话中的技能管理

云端 agent 使用 `search_skills`、`install_skill`、`create_skill` 和 `list_skill_targets`。本地 CLI 通过每轮独立的 localhost 工具通道调用同一套工具；地址及令牌仅在该轮有效，结束或停止时关闭。不需要直接修改数据库或复制内部目录。

- 搜索：按当前任务需要查询 skills.sh，最多返回 10 项。搜索结果只是候选，不视为可信指令。
- 安装：接受 GitHub `owner/repo` / 仓库 URL，以及绝对路径的本地技能目录、ZIP、TAR.GZ。GitHub 默认分支先解析为 commit，再下载对应快照。多个技能需指定准确的 YAML name，一次安装一个。
- 创建：提交根目录 `SKILL.md` 和相对路径文本资源。要求 YAML name/description；正文应描述触发条件、操作步骤、产出及验证方法。找不到适合的已有技能或用户要求创建时使用。不会自动评测或执行脚本。
- 目标：默认当前 agent；指定 `targetAgentId` 可代装到同账号 agent。普通 agent 和管理员都必须经过主人的确认，角色不授予免确认权限。
- 确认：展示来源、目标、技能、资源列表及覆盖项；创建时也展示文件内容。读取本地包之前另需确认其路径。用户拒绝、取消或切换账号不会写入配置。
- 覆盖：默认拒绝同名，显式 `replace=true` 后仍需确认。等待确认期间如果目标技能配置发生变化，需重新发起，避免覆盖并发更新。
- 生效：保存到目标配置并由现有存储层落盘全部资源，从下一条消息进入提示词。安装本身不运行脚本或安装依赖，也不改变原有工具权限。

限制沿用技能包校验：64 MiB、2,000 文件、每个 agent 最多 50 个技能。对话直接创建限 2 MB 文本；确认详情超过界面容量时会拒绝，应缩小包或使用现有手动导入界面。支持公开 GitHub 仓库，不支持私有仓库凭据及任意下载域名。

## 技能执行与文件交付

`create_file` 保存完整 UTF-8 内容（最多 4 MB），适合 HTML 演示、Markdown、CSV、JSON、代码等。文件保存在应用管理目录，不覆盖用户文件，不执行内容。结果以当前聊天中的可点击文件卡片交付；即使模型最后漏写链接，运行时也会追加真实生成的文件链接。应用管理文件仅允许所属账号打开。

`run_skill_script` 支持已启用技能中打包的 Python / JavaScript 脚本。用户逐次确认技能、脚本源码、参数、输入、输出后执行。运行目录是技能的临时副本，支持传入文本文件；最多运行 120 秒，指定输出文件合计最多 20 MB。完成后收集产物，清理临时目录。停止任务会终止所启动的进程组。失败不会报告成功或自动安装缺失依赖。

该执行器是**本机授权执行，不是操作系统沙箱**：脚本拥有应用用户的本机访问能力。工具不会继承 API Key 等应用环境凭据，但这不限制脚本主动访问本机或网络。确认界面明确展示此边界；没有授权不会执行。脚本执行不增加 agent 的永久权限。

Agent 应先用自己的技能读取、文件生成和脚本工具完成任务；仅当确实缺少必要能力时再说明原因并委托其他 agent。
